# 情報モラル・シミュレーター v3.1
## GitHub Pages + GAS リアルタイム匿名集計版

v2の「児童モード」「授業モード」に加えて、**LIVE授業**を追加しました。

v3.1では、ルートURL・`/teacher/`・`/student/` を役割ごとに完全に分離しました。
教師用ページには管理機能だけ、児童用ページには授業コード入力だけを表示します
（詳しくは「URLを教師用・児童用で分ける」の章を参照）。

## LIVE授業でできること

1. 先生が「LIVE授業を開始」
2. 6桁の授業コードを発行
3. 児童は同じGitHub Pagesを開き、「児童モード → 授業に参加」
4. 6桁コードを入力
5. 先生がシナリオを開始
6. 児童端末も同じ場面へ自動移動
7. 児童がA/B/Cを選ぶ
8. 先生の電子黒板に人数・割合が約1〜数秒単位で反映
9. 先生が「クラスではA/B/Cを選ぶ」を押す
10. 結果を全端末に公開
11. 先生が次へ進むと児童端末も追従

通信不調時は、従来どおり「手動挙手モード」で利用できます。

# 最初のセットアップ

## 1. Googleスプレッドシートを作る

例：
`情報モラルLIVE集計`

空のスプレッドシートでOKです。

## 2. Apps Scriptを開く

スプレッドシートから

`拡張機能 → Apps Script`

を開きます。

最初から入っているコードを消し、このフォルダの

`Code.gs`

の内容をすべて貼り付けます。

## 3. setup() を1回実行

Apps Script上部の関数選択から

`setup`

を選んで「実行」。

初回だけGoogleの権限確認があります。

成功するとスプレッドシートに

- `Sessions`
- `Votes`

の2シートが作られます。

## 4. Webアプリとしてデプロイ

Apps Script右上：

`デプロイ → 新しいデプロイ`

種類：
`ウェブアプリ`

設定：

- 実行するユーザー：自分
- アクセスできるユーザー：児童端末からアクセスできる範囲

学校のGoogle Workspace管理設定によって、表示される選択肢が異なる場合があります。

デプロイ後に出る

`https://script.google.com/macros/s/...../exec`

というURLをコピーします。

**必ず `/exec` で終わるURLを使います。**

## 5. config.js にURLを貼る

```js
window.IMS_CONFIG = {
  GAS_WEB_APP_URL: "https://script.google.com/macros/s/...../exec"
};
```

これで接続完了です。

## 6. GitHub Pagesへアップロード

必要なファイル（フォルダ構成もそのまま維持してください）：

- `index.html`（先生用／児童用を選ぶ案内ページ）
- `styles.css`
- `app.js`
- `config.js`
- `teacher/index.html`（先生用・LIVE管理画面）
- `student/index.html`（児童用・授業コード入力画面）

`styles.css` `app.js` `config.js` はルート直下に1つだけ置き、
`teacher/index.html` `student/index.html` からは `../` を付けて参照します。

`Code.gs` はGitHub Pagesには不要です。
GAS側に貼り付けるバックエンドコードです。

# 授業での使い方

## 先生

1. URLを電子黒板で開く
2. 「授業モード」
3. 「LIVE授業を開始」
4. 6桁コードを児童に見せる
5. シナリオを選ぶ
6. 回答数が増えるのを見る
7. A/B/Cの理由を児童に聞く
8. 「クラスでは○を選ぶ」
9. 結果を確認
10. 次の場面へ

## 児童

1. 同じGitHub Pages URLを開く
2. 「児童モード」
3. 「授業に参加」
4. 電子黒板の6桁コードを入力
5. あとは先生の進行に合わせて画面が自動で切り替わる
6. A/B/Cを選択

# 匿名性

氏名・メールアドレス・Googleアカウント情報は送信しません。

各ブラウザに

`deviceId`

というランダムIDを1つだけ保存します。

GASへ送る主な情報：

- 授業コード
- シナリオID
- 場面番号
- ランダム端末ID
- A/B/Cの回答

そのため、先生のLIVE画面では

`A 8人 / B 10人 / C 12人`

という集計だけを見る設計です。

---

# スプレッドシート

## Sessions
授業の現在位置を保存。

- 6桁コード
- セッションID
- 現在のシナリオ
- 現在の場面
- 投票中 / 結果公開 / 終了

## Votes
児童の回答ログ。

- 時刻
- 授業コード
- シナリオ
- 場面
- ランダム端末ID
- A/B/C

集計時は、同じ端末・同じ場面について最後の1票だけを数えるため、通信再送などで二重投票になりにくい設計です。

# 更新するときの注意

`Code.gs` を変更した場合は、Apps Scriptで

`デプロイ → デプロイを管理 → 編集 → 新しいバージョン`

として再デプロイしてください。

`index.html / app.js / styles.css / config.js` の変更はGitHubへpushすれば更新できます。

# 想定規模

このv3は**1クラス30〜40人程度の授業**を想定しています。

- 先生画面：集計を約1.4秒間隔で取得
- 児童端末：先生の進行状態を約3〜3.7秒間隔で確認

学校全体で多数クラスを同時接続するような規模になった場合は、
Firestore / Cloudflare Durable Objects 等のリアルタイム基盤へ移行するのが適しています。

# URLを教師用・児童用で分ける（v3.1〜）

v3.1から、ルートURL・`/teacher/`・`/student/` はそれぞれ役割が固定された別画面になりました。
「モード切替」ボタンや、もう一方のモードへの導線はページ内に存在しません。

例として公開URLが

`https://ユーザー名.github.io/info-moral-simulator/`

なら、

## ルート（案内ページ）
`https://ユーザー名.github.io/info-moral-simulator/`

先生用・児童用のどちらを開くか選ぶだけの、シンプルな案内ページです。
アプリ本体（app.js）は読み込まれません。

## 教師用（LIVE管理画面）
`https://ユーザー名.github.io/info-moral-simulator/teacher/`

LIVE授業の開始・シナリオ選択・電子黒板での挙手集計だけに絞った画面です。

## 児童用（授業コード入力のみ）
`https://ユーザー名.github.io/info-moral-simulator/student/`

6桁の授業コードを入力して参加するだけのシンプルな画面です。
個別にシナリオを選んで一人で体験する機能（旧・児童モードの個別体験）は、
このバージョンでは削除されています。

### 注意
`/teacher/` は「教師だけが使いやすいURL」に分けるためのものです。
URLを知っている人を技術的に認証する仕組みではありません。

児童に教師画面を絶対に触らせたくない場合は、別途Googleログイン等による教師認証を追加できます。
