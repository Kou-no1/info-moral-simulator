# 情報モラル・シミュレーター v2

小学校高学年向け、1人1台端末＋電子黒板に対応した静的Web教材です。

## v2で追加したもの

### 1. 先生用「授業モード」
ホーム画面のモード切替から選べます。

- 電子黒板向けの大きな表示
- A / B / C の3択
- 児童の挙手人数を `＋ / −` で入力
- その場で人数と割合を表示
- クラスで選んだ分岐だけを進める
- 結果を出す前に、選択肢について話し合える
- 最後に各場面の挙手数も振り返り表示

ネットワーク通信は使わず、先生の端末だけで動きます。

### 2. シナリオを全7テーマに拡張

基本3テーマ：
1. 炎上・拡散
2. 個人情報
3. ネット依存

追加4テーマ：
4. ネットいじめ・傍観
5. 生成AI・情報確認
6. オンラインゲーム・課金
7. なりすまし・偽アカウント

各シナリオは3場面で構成しています。

### 3. 「選択 → 結果」の間を追加
児童モードでも、選択した直後に次へ飛ばず、
「このあとどうなった？」を表示してから次の場面へ進みます。

### 4. 振り返りを4視点に
- 情報を守る
- 相手を思いやる
- 確かめる
- 使い方を決める

点数は成績ではなく、振り返り用です。

## 推奨する45分授業

### 個別体験型
- 0〜5分　導入
- 5〜25分　児童モードで基本3テーマ
- 25〜35分　振り返り
- 35〜43分　ペア・全体交流
- 43〜45分　教師まとめ

### 学級討議型
- 0〜5分　導入
- 5〜30分　授業モードで2〜3テーマ
- 各場面で挙手 → 人数入力 → 理由を数人に聞く → 結果表示
- 30〜42分　振り返り・交流
- 42〜45分　まとめ

## ファイル
- `index.html`
- `styles.css`
- `app.js`

サーバー処理・データベース・ログインは不要です。

## 起動
解凍したフォルダ内の `index.html` をChrome等で開くだけでも動作します。
学校全体にURL配布する場合は、GitHub Pagesなどの静的ホスティングに3ファイルを置きます。

## データ
児童モードの「体験済み」情報と選択したモードのみ、ブラウザの localStorage に保存します。
氏名、クラス、回答内容などは外部へ送信しません。
